⚙ Avanzado: API key de Google Drive (opcional · más fiable)

Sin clave, la carpeta se lee mediante lectores públicos. Con una API key gratis es instantánea, 100% fiable y NUNCA se satura. La clave se guarda solo en tu navegador.

❓ ¿Cómo consigo la API key gratis? (2 min)
  1. Entra a console.cloud.google.com con tu cuenta de Google.
  2. Arriba a la izquierda: crea un proyecto nuevo (nombre cualquiera, ej. "xstream").
  3. Menú ☰ → APIs y servicios → Biblioteca → busca "Google Drive API" → Habilitar.
  4. Menú ☰ → APIs y servicios → Credenciales → + Crear credenciales → Clave de API.
  5. Copia la clave (empieza por AIza…) y pégala aquí arriba. ¡Listo!
